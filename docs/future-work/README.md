# Ideas and future work

This directory records product ideas that are useful but deliberately outside
the current implementation.  Each proposal should explain the user problem,
the data and provenance contract, rebuild behaviour, safety rules and a
testable definition of done.

## Proposals

- [Reviewed filing data layer](reviewed-filing-data.md) — preserve values read
  manually from primary filings when XBRL cannot represent them reliably,
  without preventing later amended filings from being re-evaluated.
